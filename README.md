## Downloads

Each campaign release provides two download options:

- **Full Campaign** — the complete current campaign for new installations.
- **Individual Missions** — each mission is available separately for incremental updates and bandwidth-constrained installations.

Mission filenames remain stable between releases. Version information is maintained independently from the filename and is recorded within the first trigger comment of each mission.
